# 링크프라이스 — 반려동물 용품 신규 론칭 퍼포먼스 광고 제안서

## GitHub Pages 업로드 (/(root))
1. ZIP 압축을 해제합니다.
2. 저장소 최상위(`/`)에 `index.html`, `assets/`, `README.md`를 그대로 업로드합니다.
3. 저장소 → **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치 `main` · 폴더 `/(root)`를 선택하여 저장합니다.
5. 배포 URL 뒤에 `#slide-09` 등을 붙여 해당 슬라이드로 이동할 수 있습니다.

## 조작
- `→` / `←`, `Page Down` / `Page Up`으로 이동, `Home` / `End`로 처음/마지막 장 이동
- 하단 목차에서 슬라이드 바로 이동
- 모바일에서는 좌우 스와이프 및 세로 스크롤 지원

## 수정 사항
- 기존 12, 14, 15, 21, 23페이지 삭제 후 전체 페이지 번호 재정리 (총 19페이지)
- 메타 광고 전략 페이지에 배너 크리에이티브 컨셉 2종 배치
- 실운영 레퍼런스의 브랜드 식별 정보와 출처 표기 제거. 수치는 실제 제공값을 유지했으며 임의로 부풀리지 않음
- 마지막 페이지 문구를 “빠른 최적화로 빠른 매출을”로 수정하고 이메일 우선 문구 삭제

※ 배너는 원본 실소재 파일이 제공되지 않아 제안서 내 시각적 컨셉 예시로 제작했습니다. 실제 집행 소재와 혼동되지 않도록 컨셉임을 표기합니다.
